Descale

Buildup report · app uninstaller · startup manager. Nothing is touched without your confirmation.

Welcome to Descale. It separates buildup from your data — like descaling a kettle. safe items (regenerable caches) are pre-selected; review items are never pre-checked; everything cleaned goes to the Trash first, and every session can be undone from the journal.

These are Launch Agents — programs macOS starts when you log in. Deactivating renames their plist (reversible, no admin needed); activating restores and starts them. The Login Items shown in System Settings are managed by macOS itself and are not listed here. System-wide agents and daemons are read-only: they need an administrator.

🔒 What Descale knows

  • The server binds to 127.0.0.1 only — unreachable from your network.
  • Zero telemetry: no analytics, no crash reporting, no file inventories — nothing about your machine leaves it.
  • Cleaning moves files to the Trash first and every session is journalled and restorable. The one permanent action (Empty the Trash / Recycle Bin) is review-only and always requires a separate confirmation.
  • The rules database is a local file: rules/descale-rules.json.
  • The journal lives at .
  • Scans never send anything anywhere; every endpoint listed in the README runs on this machine, for this machine.

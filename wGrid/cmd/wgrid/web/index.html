Databases

Sources feeding the provider table. Sources sharing a name merge into one provider — e.g. a YouTube CSV and the Google feed both named “Google & YouTube” combine their networks. Deleting a source removes it from the config; if it was the provider’s last source, its data is deactivated immediately. Built-in defaults can be deleted too and stay deleted across restarts (re-adding them restores them). Sample feeds live in samples/ — see samples/GUIDE.md.

App Access

        
Reported grants and sandbox capabilities for installed apps. An unknown or missing entry is not the same as denied.

      

      
    

    

    

      
      
      
      
      
    

    

    
Select App Access to load inventory.

    

      Unload & delete (orange) is for launchd jobs — LaunchDaemons and
      LaunchAgents: it first unloads the job from launchd (stopping the running process so it
      does not just respawn) and then deletes the plist file.
      Delete (orange) is for bare helper binaries in
      /Library/PrivilegedHelperTools: those are plain executables, not launchd jobs, so there is
      nothing to unload — the file is removed directly. If a daemon still points at a deleted
      helper, remove the daemon too, or launchd will simply fail to start it.
      Remove (red) deletes a user TCC grant row after saving a backup. Sentinel
      must have Full Disk Access to enable it; system-database grants remain read-only here.
      Sentinel is configured for AppDeck's Elevated launch so its own app identity can receive
      that access. Every action here also exists as a terminal command — see Firewall Rules for
      firewall-specific commands.
